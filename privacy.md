# Privacy Policy

Last updated: 2026-10-04

NestFlow is a personal tool used only by its developer, on the developer's own
Google account.

## What data is accessed

NestFlow uses the Gmail API (`gmail.modify` scope) to:

- find credit card e-statement emails,
- download their PDF attachments,
- add or remove Gmail labels to mark emails as processed.

It does not send email and does not permanently delete email.

## How data is used and stored

Statement data is processed and stored only on the developer's own home server.
Statement text, with personal identifiers masked, is sent to the Google Gemini
API solely to extract transaction details. Data is not sold, shared with, or
transferred to any other third party, and is not used for advertising.

NestFlow's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
